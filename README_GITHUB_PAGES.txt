GitHub Pages 上传说明

1. 不要直接上传这个 ZIP 到 GitHub。
2. 先解压 ZIP。
3. 把解压出来的 index.html 上传到仓库根目录。
4. .nojekyll 可以一起上传，也可以不传。
5. 进入仓库 Settings -> Pages，选择 Deploy from a branch，Branch 选 main / root。
6. 等几分钟后访问 https://你的用户名.github.io/仓库名/

本版本是单文件网页：图片和简历 PDF 已经内嵌到 index.html 里，所以 GitHub 只需要这一个 index.html 也能正常显示。
